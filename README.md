# GEO/AEO-Checkliste: Wie Marken in KI-Antworten sichtbar werden

Eine praktische, produktunabhängige Checkliste für Marketing-Verantwortliche 
und Agenturen, die verstehen wollen, warum manche Marken in ChatGPT, Gemini 
und Perplexity vorkommen — und andere nicht.

## Warum das wichtig ist

KI-Systeme "wissen" nicht, was auf Ihrer Website steht, wenn sie eine 
Kaufberatungsfrage beantworten. Sie stützen sich auf Belege außerhalb der 
eigenen Domain: Reviews, Community-Diskussionen, Wissensdatenbanken, 
strukturierte Daten. Bei [sotiq](https://sotiq.ai) sind wir bei der Analyse 
tausender KI-Antworten genau auf diese Muster gestoßen — diese Checkliste 
fasst zusammen, welche Quellen dabei am stärksten zählen.

## Die fünf Hebel

### 1. Review-Plattformen
- [ ] Vollständiges Profil auf branchenüblichen Bewertungsplattformen 
      (in DACH: kununu, OMR Reviews)
- [ ] Echte, aktuelle Kundenbewertungen (keine gekauften/incentivierten)
- [ ] Konsistente Markennennung über alle Profile hinweg

### 2. Community-Präsenz
- [ ] Fachliche, unaufdringliche Beteiligung in relevanten Reddit-
      Communities/Foren
- [ ] Keine reine Werbung — Communities erkennen und entfernen das
- [ ] Kontinuität über Zeit, nicht ein einmaliger Post

> Reviews und Community-Signale sind laut unserer eigenen Auswertung die 
> zwei am stärksten gewichteten Faktoren dafür, ob eine Marke in KI-Antworten 
> überhaupt zitiert wird. Mehr zur Methodik: 
> [sotiq Entity-Analyse](https://sotiq.ai/anwendungsfaelle/entity-analyse)

### 3. Externe Autorität
- [ ] Einträge in relevanten Branchenverzeichnissen
- [ ] Erwähnungen in Fachmedien/Roundups
- [ ] Strukturierte Unternehmensdaten (Wikidata, falls Relevanzkriterien 
      erfüllt)

### 4. Eine zitierfähige eigene Seite
- [ ] Klare Definitionsabsätze, die eine Frage direkt beantworten
- [ ] Semantisches HTML, keine reinen JavaScript-Tabellen für 
      wichtige Fakten
- [ ] Strukturierte Daten (Schema.org) korrekt implementiert

> Wie eine Seite so aufgebaut wird, dass KI-Systeme sie zitieren können: 
> [sotiq GEO Optimierung] (https://sotiq.ai/anwendungsfaelle/ki-optimierung)

### 5. Markenkonsistenz
- [ ] Ein einheitlicher Markenname über alle Plattformen (Schreibweise, 
      Leerzeichen, Bindestriche)
- [ ] Google Knowledge Graph / Wikidata-Eintrag stimmt mit dem 
      tatsächlichen Markennamen überein

## Häufiger Fehler

Viele Unternehmen optimieren nur die eigene Website (klassisches SEO), 
ohne zu bedenken, dass KI-Systeme stärker auf externe, unabhängige 
Quellen vertrauen als auf Eigenaussagen.

## Weiterführend

Wer prüfen möchte, wie eine Marke aktuell in KI-Antworten dasteht — ob sie 
überhaupt genannt wird und mit welcher Tonlage — kann das automatisiert 
messen: [Wettbewerber-Tracking] (https://sotiq.ai/anwendungsfaelle/wettbewerber-tracking)

[Sentiment-Analyse] (https://sotiq.ai/anwendungsfaelle/sentiment-analyse) 
zeigt, wie positiv oder negativ eine Marke beschrieben wird.
